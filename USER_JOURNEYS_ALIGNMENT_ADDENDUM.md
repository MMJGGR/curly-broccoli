# User Journeys Alignment — IA v2 (Five Tabs + Milestones/Pro Forma)

Date: 2025-09-18
Owner: Product + Engineering

## Summary
The navigation is simplified to five tabs and a single Milestone + Pro Forma model connects daily actions (budget, goals, CRUD) to outcomes (Balance Sheet and P&L) without overwhelming users.

## Tabs
- Dashboard: Current Position + Nearest Milestone; key KPIs; sparkline; quick fixes
- Plan: Goals + Budget + Milestones + Audits; coverage bars; quick budget edits
- Balance Sheet: Current vs Pro Forma KPIs; allocation and liability composition; net worth trend; Goals Impact panel
- Cash Flow: Income/Expenses CRUD; Income Statement; Cash Flow Statement; audit banners; Trial Balance (Advanced)
- Timeline: Milestone markers; Pro Forma snapshot preview for the selected month

## Journey Alignment
- Onboarding sets planning start month (default next month) → label alignment across charts.
- Managing income/expenses/assets/liabilities instantly updates Balance Sheet and Cash Flow snapshots.
- Defining goals and allocations in Plan updates coverage bars and active milestones.
- Balance Sheet (Pro Forma) shows how the plan changes net worth and structure by a target date.
- Timeline reveals when milestones become realistic, with color‑coded likelihood and links back to Plan/Budget.

## Outcomes
- Fewer navigation decisions; calmer visuals (cards + two charts by default).
- Consistent “Current vs Milestone” pattern across tabs.
- Direct, contextual actions that make progress observable and rewarding.
